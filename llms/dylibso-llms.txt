# Dylibso

> Dylibso, Inc. is the company behind Extism, the cross-language framework for building with WebAssembly (Wasm). Its mission is AI-driven application extensibility: letting developers embed secure, sandboxed, language-agnostic plug-ins into their software. Products include the Extism plug-in framework, the Chicory pure-JVM Wasm runtime, and Turbo MCP (formerly mcp.run / XTP), a self-hosted MCP gateway and management platform.

Generated by the API Evangelist enrichment pipeline from the public Dylibso/Extism surface. No first-party llms.txt is published; this file is a faithful catalog summary.

## Company
- [Dylibso](https://dylibso.ai): Pioneering AI-driven application extensibility.
- [Dylibso on GitHub](https://github.com/dylibso): 79+ open-source repositories (Chicory, Extism tooling, mcp.run servlets, observe-sdk, modsurfer).

## Products
- [Extism](https://extism.org): The cross-language WebAssembly plug-in framework — an off-the-shelf, secure-by-default plug-in system available as a library import.
- [Extism on GitHub](https://github.com/extism): 68+ repositories including the core runtime and every Host SDK.
- [Chicory](https://github.com/dylibso/chicory): Native, dependency-free JVM WebAssembly runtime.
- [Turbo MCP](https://turbomcp.ai): Standards-compliant, self-hosted MCP gateway and management platform (formerly mcp.run / XTP), with OIDC IdP integration and audit controls.
